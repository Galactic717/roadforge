# Historical 2D RoadForge lab

This directory preserves RoadForge 0.1.0: a Python imitation-learning sandbox with synthetic graph roads, a point vehicle, and a canvas editor. It is not the current product runtime. Its architecture, model card, tests, and old UI are retained for historical reference.

The current RoadForge product is the Vite/Cesium globe at the repository root and under `web/`.
