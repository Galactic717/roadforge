# Preset road routes

These five GeoJSON-style coordinate arrays were requested from the public OSRM demo routing service on 27 September 2026 using `overview=full&geometries=geojson&steps=true`. The underlying road network comes from OpenStreetMap contributors and is subject to the Open Database License. Attribution is shown in the app and README.

The cache exists so the one-click missions can launch when live routing is unavailable. It is route geometry, not imagery or a lane-level map. Custom destinations still request a live route.
